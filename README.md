# AI-first Helpdesk Draft Service

An AI-assisted helpdesk that accepts tickets from a helpdesk webhook, drafts replies from a
knowledge base with an LLM, lets an operator approve or reject the draft, and delivers the
approved reply back to the helpdesk API.

> Status: under active development. The full setup guide is added in the final milestone.
